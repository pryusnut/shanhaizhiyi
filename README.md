# 山海志异（无名杀挑战模式扩展）

[无名杀](https://github.com/libnoname/noname)的挑战模式（BOSS）扩展。在原作者「浪琴婊」v1.108 版本的基础上修复若干BUG，优化交互逻辑并移除冗余资源，适配最新版（v1.11.5）无名杀。

**本扩展开源免费，严禁倒卖！**

## 功能特性

- 在挑战模式中添加各种版本的山海志异活动场玩法，以及地狱判官、青青子衿等活动场PVE BOSS战。
- 支持将所有官方挑战模式关卡修改为随机获取技能的肉鸽玩法（山海志异/天书乱斗），并支持修改我方上场人数为1-2人增加难度。
- 保留原作者自创的挑战BOSS提高可玩关卡量。

## 安装方法

### 方法一：zip 导入（推荐）

1. 下载本仓库代码（`extension.js` + `info.json`），全选压缩为 zip —— **zip 根目录必须直接是这两个文件**，不能包含外层文件夹。
2. 无名杀内：选项 → 扩展 → 获取扩展 → 导入扩展导入该 zip（如启动器支持可尝试直接使用无名杀打开该zip）。
3. 进入**挑战模式**，即可看到「山海志异」等关卡。

### 方法二：万能导入法

1. 无名杀内：选项 → 扩展 → 制作扩展 → 修改扩展名为山海志异 → 点击确定 → 点击保存 → 点击立即重启。
2. 将 `extension.js`、`info.json` 放入 `无名杀安装目录/extension/山海志异/`，重启游戏。
3. 进入**挑战模式**，即可看到「山海志异」等关卡。
