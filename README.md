# 山海志异（无名杀挑战模式扩展）

[无名杀](https://github.com/nonameShiJian/noname)（非人学院同人开源《三国杀》）的挑战模式（BOSS）扩展。在原作者「浪琴婊」v1.11 基础上进行现代化适配，兼容新版无名杀引擎。

**本扩展开源免费，严禁倒卖！**

## 功能特性

- 在挑战模式中添加各种版本的山海志异活动场挑战，以及地狱判官、青青子衿等活动场 PVE 模式
- 保留原作者自创的挑战 BOSS：奥利哈刚、浪琴婊、十常侍张让、永远的神、灵
- 共 64 个 BOSS 武将，按分类分组（山海志异、地狱判官、奥利哈刚、青青子衿等）
- 提供可配置项：山海关卡切换、朱果发放方式（可选随机获得技能模式）、我方登场人数（1-3 人，推荐 2 人）等

## 安装方法

### 方法一：zip 导入（推荐）

1. 下载本仓库代码（`extension.js` + `info.json`），全选压缩为 zip —— **zip 根目录必须直接是这两个文件**，不能包含外层文件夹
2. 无名杀内：设置 → 扩展 → 导入该 zip
3. 进入**挑战模式（BOSS）**，即可看到「山海志异」等关卡

### 方法二：手动放置

将 `extension.js`、`info.json` 放入 `无名杀安装目录/extension/山海志异/`，重启游戏。

### 美术素材说明（重要）

**本仓库仅包含代码，不包含美术素材**（素材版权归原版权方所有，见下文声明）。BOSS 立绘素材需自行获取：

- 大部分角色已映射到游戏内置素材（如 `image/mode/boss/character/`），无需额外文件
- 其余角色立绘请从原版扩展安装包（v1.11）中获取 `boss_*.jpg` 共 67 张，放入扩展目录，文件名与武将 id 对应
- 素材缺失时游戏仅显示空白立绘，不影响代码功能

## 现代化适配说明

本仓库在原作者 v1.11 版本基础上进行了以下修改，以兼容新版无名杀：

1. **`lib.boss` 兜底初始化**：修复非挑战模式启动时报 `Cannot set properties of undefined` 的问题
2. **武将包改由 `package.character` 加载**：修复 64 个武将从未加载的问题（原 precontent 的 `qinyin.enable` 门控恒为假）
3. 移除失效死代码（旧式 `lib.config.all.characters.push` 注册等）
4. 新增武将包菜单名称翻译
5. 部分角色美术改用无名杀内置素材
6. 修复关卡翻译覆盖失效（消除 duplicated translate 警告）

`extension.js` 文件头部有完整的修改说明注释。
